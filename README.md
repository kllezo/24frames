---

## 24frames-website

Built with Next.js 16 (Turbopack), TypeScript, and GSAP ScrollTrigger:

- **24-Frame Cinematic Preloader:** Art-directed 5-phase opening sequence with overlapping fade choreography.
- **Founder & Sculptural Recognition Wall:** Two curved champagne-toned gallery rails with 6 verified achievement artefacts and click-to-expand editorial view.
- **The Collection:** Pure scroll-driven photographic installation with organic vertical offsets.
- **Signature Stacks:** 3D perspective photo stacks with focal pull-out interaction.
- **Aesthetic:** Warm ivory (`#FAF8F2`) and obsidian cinema tones, editorial serif typography (Cinzel, Italiana, Cormorant Garamond), and native cursor precision.

### Getting Started

```bash
cd 24frames-website
npm install
npm run dev
```

Visit `http://localhost:3000` to view the live website.
