# Research Limitations & Methodology Constraints

## Access & Platform Constraints
1. **Instagram Direct Scraping**: Instagram requires authenticated user sessions for comprehensive historical pagination. Headless unauthenticated requests face HTTP 401/login walls. Fallbacks used: Google Web Indexing cache, open web embeds, YouTube linked posts, cross-platform vendor tags, public media articles.
2. **Dynamic Web Application States**: Single Page Applications and JavaScript-rendered directory pages may conceal certain older pagination without active DOM execution.
3. **Third-Party Directory Attribution**: Platforms like WedMeGood, WeddingWire, and Justdial may list self-reported packages, prices, or year established without independent legal verification.
4. **Name Ambiguity**: Multiple photographers and studios globally and in India utilize "24 Frames" (e.g. 24 Frames UK, 24 Frames Mumbai, 24 Frames Film Co). Rigorous filtering is applied to isolate only Phani Gogireddy's Hyderabad/South India studio.
