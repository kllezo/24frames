# Research Evidence Repository

This directory archives primary and secondary evidentiary material gathered during the 24 Frames Photography and Luxe Events investigation:

- `source-snapshots/`: Raw HTML / markdown snapshots of web pages, directories, and profiles.
- `captions/`: Extracted and verified social captions, hashtags, and credits.
- `transcripts/`: YouTube film transcripts, interview logs, and audio extractions.
- `public-media-references/`: Referenced public media URLs, stills analysis, and visual breakdowns.
